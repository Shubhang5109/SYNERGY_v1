    5. Assumptions and scope

    • Solid line: mean-field ODE (Eq. 3) with hazard from Eqs. 8–12, integrated by RK4 (h = 0.005 h). It is exact for the mean only in the linear regime and is not meaningful below about one cell per well (Section 3.1).
    • Thin lines: τ-leaping approximation (Δt = 0.01 h) of the five-channel Markov chain of Table S3, with the same deterministic hazard. It is an approximation to the exact chain.
    • Growth-inhibition fractions ς are at the default 0 (purely lethal action). Each agent is a single bolus with first-order decay (Eq. 8). Initial state: all cells replicating, e(0) = 0.
    • MIC values use Proposition 6 and apply when κX = 0. The null is φ = 0, θ = 1 with the same single-agent parameters.
    • Resistance functional (Eqs. 28–29): lineage birth rate b = g₀(1 − c_R); death rate is the loss hazard with C_A → f_R·C_A and φ → χφ, θ unchanged. It assumes a deterministic sensitive path and lineages far from carrying capacity. Set θ = 1 to model a preparation that does not act on the mutant.
    • t* (Eq. 34) holds in the linear engagement regime (hₑ = 1, x₀ ≪ Cₑ); the numerical peak of e(t) is shown for the general case. The bound of Proposition 9 needs constant a, θ = 1, κX = 0.
